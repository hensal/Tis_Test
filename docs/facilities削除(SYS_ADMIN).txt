Endpoint Note

Excel title says:
POST /facilities/{facilityid}

facilities.md says:
DELETE /facilities/{facilityId}

Current backend supports both:

POST http://localhost:8081/facilities/<facilityId>
DELETE http://localhost:8081/facilities/<facilityId>

For Excel testing, use POST.
For REST API testing, DELETE is also valid.


Common Postman Setup

Base URL:
http://localhost:8081

Portable setup for any computer:
If the backend runs on another host or port, replace http://localhost:8081.
Always run the SQL in this document on the target computer's DB first.

Headers:
Authorization: Bearer <SYS_ADMIN_ACCESS_TOKEN>

Body:
No body is required.
Excel says all body request parameters are ignored.


Before Testing: Find IDs

1. Find an active facility.

SELECT facility_id, parent_id, facility_name, deleted_at
FROM facilities_tree
WHERE deleted_at IS NULL
ORDER BY facility_id;


2. Find a non-existing facility ID.

SELECT COALESCE(MAX(facility_id), 0) + 999999 AS non_existing_facility_id
FROM facilities_tree;

Use this as:
<non_existing_facility_id>


3. Find a full delete target with children, grandchildren, and related data.

SELECT
  p.facility_id,
  p.facility_name,
  COUNT(DISTINCT child.facility_id) AS child_count,
  COUNT(DISTINCT grandchild.facility_id) AS grandchild_count,
  COUNT(DISTINCT frp.facility_role_permission_id) AS role_count,
  COUNT(DISTINCT fi.image_id) AS image_count,
  COUNT(DISTINCT m.map_id) AS map_count,
  COUNT(DISTINCT mp.map_point_id) AS map_point_count,
  COUNT(DISTINCT e.equipment_id) AS equipment_count,
  COUNT(DISTINCT a.annotation_id) AS annotation_count
FROM facilities_tree p
LEFT JOIN facilities_tree child
  ON child.parent_id = p.facility_id
 AND child.deleted_at IS NULL
LEFT JOIN facilities_tree grandchild
  ON grandchild.parent_id = child.facility_id
 AND grandchild.deleted_at IS NULL
LEFT JOIN facility_role_permission frp
  ON frp.facility_id = p.facility_id
 AND frp.deleted_at IS NULL
LEFT JOIN facility_images fi
  ON fi.facility_id = p.facility_id
 AND fi.deleted_at IS NULL
LEFT JOIN maps m
  ON m.facility_id = p.facility_id
 AND m.deleted_at IS NULL
LEFT JOIN map_points mp
  ON mp.facility_id = p.facility_id
 AND mp.deleted_at IS NULL
LEFT JOIN equipments e
  ON e.facility_id = p.facility_id
 AND e.deleted_at IS NULL
LEFT JOIN annotations a
  ON a.facility_id = p.facility_id
 AND a.deleted_at IS NULL
WHERE p.deleted_at IS NULL
GROUP BY p.facility_id, p.facility_name
HAVING COUNT(DISTINCT child.facility_id) > 0
   AND COUNT(DISTINCT grandchild.facility_id) > 0
ORDER BY p.facility_id;

Use one facility_id as:
<full_delete_facility_id>


4. Find a simple delete target with no children or grandchildren.

SELECT ft.facility_id, ft.parent_id, ft.facility_name
FROM facilities_tree ft
WHERE ft.deleted_at IS NULL
  AND NOT EXISTS (
      SELECT 1
      FROM facilities_tree child
      WHERE child.parent_id = ft.facility_id
        AND child.deleted_at IS NULL
  )
ORDER BY ft.facility_id;

Use one facility_id as:
<simple_delete_facility_id>


Before Delete: Save Target/Descendant IDs

For full delete target:

WITH RECURSIVE targets AS (
    SELECT facility_id, parent_id, facility_name
    FROM facilities_tree
    WHERE facility_id = <full_delete_facility_id>
      AND deleted_at IS NULL
    UNION ALL
    SELECT child.facility_id, child.parent_id, child.facility_name
    FROM facilities_tree child
    JOIN targets parent
      ON child.parent_id = parent.facility_id
    WHERE child.deleted_at IS NULL
)
SELECT *
FROM targets
ORDER BY facility_id;

Use the returned IDs as:
<target_facility_ids>
