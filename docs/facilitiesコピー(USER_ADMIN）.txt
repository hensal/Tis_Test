Current code note:
The current backend treats USER_ADMIN like SYS_ADMIN.
If the bearer token contains USER_ADMIN, the API does not require FACILITY_ROLE_PERMISSION permission_id = 10.

Therefore:
- USER_ADMIN success tests do not need DB permission rows.
- Excel case 1-1-15 cannot return permission_denied when the token really has USER_ADMIN.
- To test 1-1-15 permission_denied, use a non-admin token such as R_USER01 with no permission_id = 10 row.

Endpoint:
POST http://localhost:8081/facilities/<facilityId>/copy

Headers:
Authorization: Bearer <USER_ADMIN_ACCESS_TOKEN>
Content-Type: application/json

  FROM facilities_tree
  WHERE parent_id = <copied_full_facility_id>
    AND deleted_at IS NULL

copied_descendants AS (
  WITH RECURSIVE d AS (
    SELECT facility_id, parent_id, facility_name
    FROM facilities_tree
    WHERE parent_id = <copied_full_facility_id>
      AND deleted_at IS NULL
    UNION ALL
    SELECT child.facility_id, child.parent_id, child.facility_name
    FROM facilities_tree child
    JOIN d parent
      ON child.parent_id = parent.facility_id
    WHERE child.deleted_at IS NULL
