facilitiesコピー(SYS_ADMIN） Postman Test Steps

Source Excel sheet:
APIテスト仕様書(facilities).xlsx
Sheet: facilitiesコピー(SYS_ADMIN）

Important endpoint note:
The Excel title says:
POST /facilities/{facilityid}/move

But this is the copy test sheet. In the current backend and facilities.md,
the copy API endpoint is:

POST /facilities/{facilityId}/copy

Use /copy for Postman copy testing.

Current implementation notes:
The current backend copies facilities_tree recursively, creates copied DB rows for facility_images, maps,
facility_role_permission, equipments, map_points, hotspots, and creates new FILES rows for copied
facility_images/maps. Annotations are not copied.

Before running the FULL copy cases, first create all required copy-check data with the SQL below.
Then run the finder SQL and use the returned facility_id as the copy source.


Common Postman Setup

Base URL:
http://localhost:8081

Portable setup for any computer:
If the backend runs on another host or port, replace http://localhost:8081 with that computer's backend URL.

Examples:
http://localhost:8081/facilities/<facilityId>/copy
http://192.168.1.20:8081/facilities/<facilityId>/copy

Do not hardcode facility IDs from one computer.
Always run the SQL in this document on the target computer's DB first, then replace placeholders like:
<valid_facility_id>
<valid_parent_id>
<valid_target_facility_id>
<response_facility_id>

Method:
POST

Endpoint format:
{{baseUrl}}/facilities/{{facilityId}}/copy

Headers:
Authorization: Bearer <SYS_ADMIN_ACCESS_TOKEN>
Content-Type: application/json

Normal request body format:
{
  "parent_id": <parent_id>,
  "target_facility_id": <target_facility_id_or_null>
}

target_facility_id rule:
You cannot use any random target_facility_id from the DB.
If target_facility_id is not NULL, it must be a facility directly under the same parent_id.

Example:
{
  "parent_id": 1110,
  "target_facility_id": 1111
}

This is valid only if facility_id 1111 has parent_id 1110.

Check with SQL:

SELECT COUNT(*)
FROM facilities_tree
WHERE facility_id = 1111
  AND parent_id = 1110
  AND deleted_at IS NULL;

If count = 1, the combination is valid.
If count = 0, the API should return an error.

If you want to copy to the first position under parent_id 1110, use:
{
  "parent_id": 1110,
  "target_facility_id": null
}

0-A. Check that the FULL copy source row now exists.

SQL:

SELECT
  ft.facility_id,
  ft.parent_id,
  ft.facility_name,
  COUNT(DISTINCT fi.image_id) AS vr_image_count,
  COUNT(DISTINCT m.map_id) AS map_count,
  COUNT(DISTINCT mp.map_point_id) AS map_point_count,
  COUNT(DISTINCT frp.facility_role_permission_id) AS role_count,
  COUNT(DISTINCT e.equipment_id) AS equipment_count,
  COUNT(DISTINCT child.facility_id) AS child_count
FROM facilities_tree ft
LEFT JOIN facility_images fi
  ON fi.facility_id = ft.facility_id
 AND fi.deleted_at IS NULL
LEFT JOIN maps m
  ON m.facility_id = ft.facility_id
 AND m.deleted_at IS NULL
LEFT JOIN map_points mp
  ON mp.target_id = ft.facility_id
 AND mp.deleted_at IS NULL
LEFT JOIN facility_role_permission frp
  ON frp.facility_id = ft.facility_id
 AND frp.deleted_at IS NULL
LEFT JOIN equipments e
  ON e.facility_id = ft.facility_id
 AND e.deleted_at IS NULL
LEFT JOIN facilities_tree child
  ON child.parent_id = ft.facility_id
 AND child.deleted_at IS NULL
WHERE ft.deleted_at IS NULL
GROUP BY ft.facility_id, ft.parent_id, ft.facility_name
HAVING COUNT(DISTINCT fi.image_id) > 0
   AND COUNT(DISTINCT m.map_id) > 0
   AND COUNT(DISTINCT mp.map_point_id) > 0
   AND COUNT(DISTINCT frp.facility_role_permission_id) > 0
   AND COUNT(DISTINCT e.equipment_id) > 0
   AND COUNT(DISTINCT child.facility_id) > 0
ORDER BY ft.facility_id;

Expected:
At least 1 row is returned.
Use the returned facility_id as <valid_facility_id> for FULL copy tests.

Get source and copied recursive trees:

WITH RECURSIVE source_tree AS (
  SELECT facility_id, parent_id, facility_name, sort_order, tree_level
  FROM facilities_tree
  WHERE facility_id = 1100
  UNION ALL
  SELECT child.facility_id, child.parent_id, child.facility_name, child.sort_order, child.tree_level
  FROM facilities_tree child
  JOIN source_tree parent
    ON child.parent_id = parent.facility_id
  WHERE child.deleted_at IS NULL
),
copied_tree AS (
  SELECT facility_id, parent_id, facility_name, sort_order, tree_level
  FROM facilities_tree
  WHERE facility_id = <response_facility_id>
  UNION ALL
  SELECT child.facility_id, child.parent_id, child.facility_name, child.sort_order, child.tree_level
  FROM facilities_tree child
  JOIN copied_tree parent
    ON child.parent_id = parent.facility_id
  WHERE child.deleted_at IS NULL
)
SELECT
  (SELECT COUNT(*) FROM source_tree) AS source_tree_count,
  (SELECT COUNT(*) FROM copied_tree) AS copied_tree_count;

Expected:
source_tree_count = copied_tree_count

SELECT
  ft.facility_id,
