Endpoint Note

Excel title says:
POST /facilities/{facilityid}

facilities.md says:
DELETE /facilities/{facilityId}

Current backend supports both:

POST http://localhost:8081/facilities/<facilityId>
DELETE http://localhost:8081/facilities/<facilityId>

For Excel testing, use POST.


Difference From SYS_ADMIN

Most delete test cases are the same as SYS_ADMIN.

USER_ADMIN has one extra permission case:

1-1-8:
facility_idの「10:施設編集」ロールを持っていない

Expected:
If the USER_ADMIN token does not have a role that has permission_id = 10 for the request facility_id,
the API returns permission_denied.


Common Postman Setup

Base URL:
http://localhost:8081

Portable setup for any computer:
If the backend runs on another host or port, replace http://localhost:8081.
Always run the SQL on that computer's DB first.

Headers:
Authorization: Bearer <USER_ADMIN_ACCESS_TOKEN>

Body:
No body is required.
All body request parameters are ignored.


Before Testing: Find USER_ADMIN Role Values

Decode the USER_ADMIN access token.

Find role values under:
resource_access
realm_access

The backend removes ROLE_ prefix if present.

Example:
JWT authority ROLE_USER_ADMIN becomes:
USER_ADMIN

Use the role value in SQL as:
<USER_ADMIN_ROLE>


Before Testing: Find IDs

1. Find an active facility to delete.

SELECT facility_id, parent_id, facility_name
FROM facilities_tree
WHERE deleted_at IS NULL
ORDER BY facility_id;

Case 1-1-3: Valid USER_ADMIN access token with permission

Before running this success case, insert or confirm permission_id = 10 exists.

SQL:

SELECT COUNT(*) AS edit_permission_count
FROM facility_role_permission
WHERE permission_id = 10
  AND facility_id = <request_facility_id>
  AND keycloak_role_id IN ('<USER_ADMIN_ROLE>')
  AND deleted_at IS NULL;

edit_permission_count >= 1

}

Case 1-1-8: USER_ADMIN does not have facility edit permission

Purpose:
Confirm USER_ADMIN cannot delete a facility without permission_id = 10 for that facility.

Step 1: Confirm permission count is 0.

SELECT COUNT(*) AS edit_permission_count
FROM facility_role_permission
WHERE permission_id = 10
  AND facility_id = <request_facility_id>
  AND keycloak_role_id IN ('<USER_ADMIN_ROLE>')
  AND deleted_at IS NULL;

Expected:
edit_permission_count = 0

Step 2: Send request.

POST http://localhost:8081/facilities/<request_facility_id>

Headers:
Authorization: Bearer <USER_ADMIN_ACCESS_TOKEN>

Expected:
{
  "success": false,
  "error_code": "permission_denied",
  "message": "施設を登録する権限がありません",
  "errors": null,
  "data": null
}

Important checks:
success = false
error_code = permission_denied
data = null

Step 3: Add permission and confirm success.

INSERT INTO facility_role_permission (
    permission_id,
    facility_id,
    keycloak_role_id,
    keycloak_role_name,
    created_at,
    updated_at
)
VALUES (
    10,
    <request_facility_id>,
    '<USER_ADMIN_ROLE>',
    '<USER_ADMIN_ROLE>',
    CURRENT_TIMESTAMP,
    CURRENT_TIMESTAMP
);

Then rerun:

POST http://localhost:8081/facilities/<request_facility_id>

Expected:
success = true
